class SimpleUNet(nn.Module):
    """Simplified U-Net for demo purposes with batch normalization, LeakyReLU, dropout and sigmoid activation."""

    def __init__(self, in_channels=3, out_channels=1, dropout_p=0.2):
        super().__init__()

        # Encoder (downsampling)
        self.enc1 = self._conv_block(in_channels, 32, dropout_p)
        self.enc2 = self._conv_block(32, 64, dropout_p)
        self.enc3 = self._conv_block(64, 128, dropout_p)

        # Decoder (upsampling)
        self.dec3 = self._conv_block(128 + 64, 64, dropout_p)
        self.dec2 = self._conv_block(64 + 32, 32, dropout_p)
        self.dec1 = nn.Conv2d(32, out_channels, 1)

        self.pool = nn.MaxPool2d(2)
        self.upsample = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)
        self.sigmoid = nn.Sigmoid()  # Sigmoid activation for final output

    def _conv_block(self, in_ch, out_ch, dropout_p=0.2):
        """Conv block with batch normalization and LeakyReLU: Conv -> BN -> LeakyReLU -> Dropout -> Conv -> BN -> LeakyReLU -> Dropout"""
        return nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.LeakyReLU(negative_slope=0.2, inplace=True),
            nn.Dropout2d(dropout_p),
            nn.Conv2d(out_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.LeakyReLU(negative_slope=0.2, inplace=True),
            nn.Dropout2d(dropout_p)
        )

    def forward(self, x):
        # Encoder
        e1 = self.enc1(x)          # 64x64
        e2 = self.enc2(self.pool(e1))  # 32x32
        e3 = self.enc3(self.pool(e2))  # 16x16

        # Decoder with skip connections
        d3 = self.dec3(torch.cat([self.upsample(e3), e2], 1))  # 32x32
        d2 = self.dec2(torch.cat([self.upsample(d3), e1], 1))  # 64x64
        out = self.dec1(d2)

        # Apply sigmoid activation to final output
        out = self.sigmoid(out)

        return out

## 🧩 1. What U-Net is

**U-Net** is a neural network architecture designed for **image segmentation**, originally for biomedical images.
It takes an input image and predicts a **pixel-wise map** (mask) of the same size, where each pixel is classified as belonging to some class (e.g. organ, tumor, background).

It’s called *U-Net* because of its **U-shaped structure**:

```
Input → [Encoder ↓] → [Bottleneck] → [Decoder ↑] → Output
```

The encoder *compresses* spatial information into deep features,
and the decoder *reconstructs* pixel-level predictions using **skip connections** from the encoder.

---

## 🧱 2. Structure of your `SimpleUNet`

Let’s break down the components in the code.

### 🔹 Encoder (downsampling path)

```python
self.enc1 = self._conv_block(in_channels, 32)
self.enc2 = self._conv_block(32, 64)
self.enc3 = self._conv_block(64, 128)
```

* Each encoder block uses two convolutions with **batch normalization**, **LeakyReLU**, and **dropout**.
* Each block doubles the number of filters, so the network learns more abstract features at lower resolutions.
* Between blocks, you apply:

  ```python
  self.pool = nn.MaxPool2d(2)
  ```

  which halves the spatial resolution (e.g. 64×64 → 32×32 → 16×16).

So:

| Encoder stage | Channels | Spatial size (example) |
| ------------- | -------- | ---------------------- |
| enc1          | 3 → 32   | 64×64                  |
| enc2          | 32 → 64  | 32×32                  |
| enc3          | 64 → 128 | 16×16                  |

---

### 🔹 Decoder (upsampling path)

```python
self.dec3 = self._conv_block(128 + 64, 64)
self.dec2 = self._conv_block(64 + 32, 32)
self.dec1 = nn.Conv2d(32, out_channels, 1)
```

* The decoder mirrors the encoder.
* Instead of pooling, it **upsamples** feature maps:

  ```python
  self.upsample = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)
  ```

  which doubles the spatial resolution.
* Each decoder block concatenates the upsampled features with the corresponding encoder’s output:

  ```python
  torch.cat([self.upsample(e3), e2], 1)
  ```

  These are the **skip connections** that preserve fine-grained spatial details lost during downsampling.

| Decoder stage | Input (concat) | Output channels | Spatial size |
| ------------- | -------------- | --------------- | ------------ |
| dec3          | up(e3) + e2    | 64              | 32×32        |
| dec2          | up(d3) + e1    | 32              | 64×64        |
| dec1          | → 1×1 conv     | out_channels    | 64×64        |

---

### 🔹 Output layer

```python
self.dec1 = nn.Conv2d(32, out_channels, 1)
self.sigmoid = nn.Sigmoid()
```

* The final `1×1` convolution maps feature maps to the number of **output channels** (e.g. 1 for binary segmentation, 3 for RGB mask, etc.).
* `Sigmoid` squashes the outputs to `[0,1]`, which you can interpret as probabilities.

---

### 🔹 `_conv_block`

Each block performs:

```
Conv2D → BatchNorm → LeakyReLU → Dropout
         ↓
Conv2D → BatchNorm → LeakyReLU → Dropout
```

This helps:

* **Conv2D:** Learn spatial filters.
* **BatchNorm:** Stabilize training.
* **LeakyReLU:** Prevent dead neurons (common in medical segmentation).
* **Dropout:** Add regularization, preventing overfitting.

---

## 🧮 3. The forward pass

```python
def forward(self, x):
    e1 = self.enc1(x)
    e2 = self.enc2(self.pool(e1))
    e3 = self.enc3(self.pool(e2))

    d3 = self.dec3(torch.cat([self.upsample(e3), e2], 1))
    d2 = self.dec2(torch.cat([self.upsample(d3), e1], 1))
    out = self.dec1(d2)

    return self.sigmoid(out)
```

Here’s what happens for a 64×64 input:

| Step  | Operation                    | Output shape (channels × H × W) |
| ----- | ---------------------------- | ------------------------------- |
| `e1`  | Conv                         | (32, 64, 64)                    |
| `e2`  | Pool + Conv                  | (64, 32, 32)                    |
| `e3`  | Pool + Conv                  | (128, 16, 16)                   |
| `d3`  | Upsample(e3)+concat(e2)→Conv | (64, 32, 32)                    |
| `d2`  | Upsample(d3)+concat(e1)→Conv | (32, 64, 64)                    |
| `out` | 1×1 Conv + Sigmoid           | (1, 64, 64)                     |

---

## 🧠 4. Key ideas of U-Net

* **Encoder** extracts semantic (what) features.
* **Decoder** reconstructs spatial (where) information.
* **Skip connections** combine both — allowing precise localization.
* **Symmetric structure** (down then up) → the “U” shape.

---

## 💡 5. Why this version is “simple”

This is a smaller, lighter version of the full U-Net:

* Only 3 encoder–decoder levels (instead of 4–5).
* Fewer filters (32→64→128 instead of 64→128→256→512).
* No bottleneck block.
* Uses `Upsample` instead of `ConvTranspose2d` (faster, simpler).

It’s good for **testing or small datasets** (like medical slice data), and runs easily on modest GPUs.
